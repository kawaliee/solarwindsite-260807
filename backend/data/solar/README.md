# 일사량 원본 파일

태양광 사업성 판정의 근거가 되는 **연평균 일사량 격자**를 둔다.
풍력에서 풍황이 하는 자리를 태양광에서는 이 자료가 맡는다.

---

## 어디에 무엇을 두는가

```
backend/data/solar/
├── kma_resource_map/    기상청 태양기상자원지도 (netCDF, 연평균)   ← 주 판정
└── gsa/                 Global Solar Atlas (GeoTIFF, 선택)        ← 교차검증
```

컨테이너에서는 `/app/data/solar/` 로 보인다(`./backend:/app` 마운트).
**파일을 넣기만 하면 즉시 반영된다** — 재빌드·재시작이 필요 없다.

---

## 1. 기상청 태양기상자원지도 (주 판정)

국내 공공자료 가운데 **연평균이면서 경사면 일사량까지** 담고 있는 유일한 자료다.
우리는 DEM으로 경사도·사면향을 이미 내고 있어 궁합이 맞는다.

| | |
|---|---|
| 받는 곳 | https://data.kma.go.kr/data/weatherResourceMap/selectWeatherResourceMapSlaNew.do?srt=ANN&pgmNo=756 |
| 경로 | 기상자료개방포털 로그인 → **연평균(ANN)** 선택 → 내려받기 |
| 형식 | netCDF (`.nc`) |
| 항목 | 수평면 일사량 · **경사면 일사량**(지형효과 반영) |
| 둘 곳 | `kma_resource_map/` — 압축이면 풀어서 `.nc` 만 남긴다 |

⚠️ 기상청이 **"수치모델 기반이라 관측값과 차이가 있음"** 을 명시했다.
그래서 이 값 하나로 단정하지 않고 아래 둘과 나란히 제시한다.

---

## 2. 쓰지 않기로 한 것 — KIER 태양에너지 시공간정보 API

공공데이터포털에 있고 이름도 그럴듯하지만 **판정에 쓰지 않는다.**

**시간별(순간) 값**이라 연평균이 아니다. 연평균을 얻으려면 지점당 8,760번을
호출해야 하는데 일 한도가 10,000건이라 스크리닝에 성립하지 않는다.

같은 기관의 **풍력 API에서 이미 같은 함정에 걸린 적이 있다**(`kier.py` 참조 —
삼척 능선 120m 값이 0.99m/s로 나왔다). 이름이 '자원정보'라고 해서 장기 평균인
것은 아니다.

---

## 3. 자동으로 받는 것 (직접 받을 필요 없음)

| 출처 | 방식 | 비고 |
|---|---|---|
| Global Solar Atlas (Solargis) | `api.globalsolaratlas.info` 지점 조회 | **인증키 불필요**. 250m 장기평균. World Bank/ESMAP 자료로 사업성 검토의 사실상 표준 |
| 기상청 ASOS 일사 관측 | 기존 ASOS 연동 재사용 | 관측소 30여 곳뿐이라 부지에서 멀지만, **모델값이 아닌 실측** |

GeoTIFF를 미리 받아 두고 싶으면 https://globalsolaratlas.info/download 에서
국가 단위로 받아 `gsa/` 에 넣는다. 없으면 지점 조회로 그때그때 받는다.

---

## 왜 셋을 함께 쓰는가

일사량은 **발전량과 수익을 직접 가르는 수치**다. 한 자료로 단정하면 조용히
틀린다. 세 값을 나란히 놓고 편차를 밝히면 담당자가 어느 값을 쓸지 판단할 수
있다 — 풍황에서 "현장 실측 최소 1년 자료를 쓰십시오"라고 안내하는 것과 같은
원칙이다.

값이 서로 크게 어긋나면 그 사실 자체를 항목에 적는다. 평균을 내어 하나로
뭉개지 않는다.

참고 — 2026-08 실측 (GHI, kWh/m²/yr)

| 지점 | Global Solar Atlas | PVGIS(ERA5) |
|---|---|---|
| 홍성 | 1,484 | 1,551 |
| 삼척 | 1,462 | 1,548 |
