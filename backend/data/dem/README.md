# DEM (수치표고모델) 원본 파일

경사도·향(向) 산출의 원본이 되는 표고 격자를 둔다. 태양광 이격거리 조례
가운데 거리가 아닌 **지형 조건**을 규정한 조항(예: 홍성군 [별표 26]
"경사도가 15도 이상인 산지에 입지하지 아니할 것")을 판정하려면 이 자료가
필요하다. V-World 토지특성의 '지형지세'(급경사·고지)는 **공시지가 산정용
구분**이라 이 판정에 쓸 수 없다.

---

## 어디에 두는가

출처별로 하위 폴더를 나눈다. 같은 지역을 여러 출처로 갖게 되는데,
어느 파일에서 나온 값인지 판정 근거에 적어야 하기 때문이다.

```
backend/data/dem/
├── ngii_5m/      국토지리정보원 5m  (도엽 1:5,000 단위)
├── ngii_90m/     국토지리정보원 90m
└── copernicus/   Copernicus GLO-30 (내려받기 자동)
```

컨테이너에서는 `/app/data/dem/` 으로 보인다(`./backend:/app` 마운트).
**파일을 넣기만 하면 즉시 반영된다** — 이미지 재빌드나 재시작이 필요 없다.

---

## 파일 이름

받은 이름을 그대로 둔다. 도엽번호가 이름에 들어 있어(예: `37709093.asc`)
어느 구역인지 되짚을 수 있고, 임의로 고치면 그 단서가 끊긴다.

압축(zip)으로 받았다면 풀어서 `.asc`/`.img` 만 남긴다.

---

## 포맷

| 확장자 | 판단 |
|---|---|
| `.asc` (ESRI ASCII Grid) | **권장.** 헤더가 텍스트라 추가 라이브러리 없이 읽힌다 |
| `.img` (ERDAS) | 읽을 수 있으나 rasterio가 필요하다 |
| `.tif` (GeoTIFF/COG) | Copernicus가 이 형식이다 |
| `.pdf` | 인쇄용. 쓸 수 없다 |

---

## ⚠️ 좌표계 — 파일에 안 적혀 있다

ESRI ASCII Grid 헤더에는 격자 정보만 있고 **좌표계가 없다.**

```
ncols        2000
nrows        2500
xllcorner    345000.000
yllcorner    550000.000
cellsize     5.0
NODATA_value -9999
```

국내 DEM은 대개 EPSG:5186(중부원점 TM) 또는 EPSG:5179(UTM-K)인데,
둘을 바꿔 읽으면 **수십 km 떨어진 곳의 경사도**가 나온다. 오류가 아니라
그럴듯한 숫자로 나오므로 눈으로는 못 잡는다.

그래서 새 파일을 넣을 때는 `xllcorner`/`yllcorner` 값을 이 폴더의
`sources.json`에 좌표계와 함께 적는다. 추측해서 읽지 않는다.

```json
{
  "ngii_5m": {
    "epsg": 5186,
    "note": "국토정보플랫폼 공개DEM, 1:5,000 도엽, 2026-08 내려받음"
  }
}
```

`sources.json`이 없거나 해당 출처가 적혀 있지 않으면 그 파일은 **읽지 않고**
'확인 필요'로 남긴다.

---

## 커버리지 주의

국토지리정보원 **5m는 도시지역 중심**으로 구축돼 있다(2005~2021 항공레이저).
태양광 검토 대상인 산지는 빠져 있을 수 있으므로, 대상 지역에 자료가
실제로 있는지 먼저 확인한다. 없으면 90m 또는 Copernicus GLO-30(30m,
산지 포함 전국)으로 대신한다.
