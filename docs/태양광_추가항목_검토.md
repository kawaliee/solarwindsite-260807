## 1. 송전선로 이격 · 지장물 — 무엇을 말하는가

제가 뭉뚱그려 적어 혼란을 드렸습니다. **두 가지 다른 이야기**입니다.

### 1.1 송전선로 이격 — 부지 **위를 지나는** 선로

한전 가공선로가 부지 상공을 통과하면 그 아래에는 모듈을 놓을 수 없습니다.
선로 폭에 이격거리를 더한 만큼 **띠 모양으로 부지가 잘려 나갑니다**.

```
      ┌─────────────────────────────┐
      │        사업부지              │
      │  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │ ← 154kV 가공선로 통과
      │  ▓  이 띠는 배치 불가   ▓  │   (선로 폭 + 이격)
      │  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │
      └─────────────────────────────┘
```

부지 한가운데를 지나면 사업이 두 조각으로 갈려 어레이 배치가 크게 나빠집니다.
**계통 연계는 선로가 가까울수록 유리한데, 부지 위를 지나면 오히려 손해**라는 점이
직관과 어긋나 놓치기 쉽습니다.

### 1.2 지장물(支障物) — 부지 **안에 이미 있는 것**

이설하거나 피해서 배치해야 하는 기존 시설물입니다.

| 지장물 | 확인 가능한 자료 |
|---|---|
| 송전탑·전주 | OSM (일부) |
| **농업용 용배수로** | **연속지적 지목 `구거`** |
| **묘지** | **연속지적 지목 `묘`** |
| 관정·저수시설 | 공개 자료 없음 — 현장 확인 |
| 상하수도·가스관 | 공개 자료 없음 — 굴착 전 지하시설물 조회 |

태양광은 부지를 빽빽하게 채우는 사업이라 **지장물 면적이 곧 발전량 손실**입니다.
풍력은 지장물을 피해 호기를 옮기면 되지만 태양광은 그만큼 용량이 줄어듭니다.

### 1.3 구현 범위

지금 있는 자료로 되는 것만 넣습니다.

- **부지 통과 송전선로** — OSM 송전선로를 이미 받고 있다(`OsmGridProvider`).
  구역과 교차하는 선로가 있으면 그 사실과 길이를 낸다.
- **부지 내 구거·묘지 필지** — 연속지적 지목으로 파악. 면적을 합산해 낸다.
- 배전선로(22.9kV)·지하시설물은 **공개 자료가 없다.** 없는 것을 있는 척하지 않고
  '현장·한전 확인 필요'로 남긴다.

## 2. 문화재 지표조사 — ⚠️ 법이 바뀌었습니다

**3만㎡ 기준을 그대로 넣으면 안 됩니다.** 원문을 확인한 결과입니다.

「매장유산 보호 및 조사에 관한 법률」에서 **사업시행자의 의무 지표조사 조항이
2024-02-13 개정으로 삭제**되었습니다.

- 제6조 → 삭제 흔적, 현행은 **제6조의2(국가 등에 의한 매장유산 지표조사)**
  "**국가 또는 지방자치단체는** … 지표조사를 **할 수 있다**"
- 제7조제1항·제3항·제4항 모두 `삭제 <2024.2.13>`

즉 **"사업면적 3만㎡ 이상이면 사업시행자가 지표조사를 해야 한다"는 조항이
현행법에 없습니다.** 종전 기준을 그대로 옮기면 폐지된 의무를 근거로 다는 셈입니다.

### 그래서 이렇게 넣습니다

항목은 **추가하되**, 판정 문구를 현행에 맞춥니다.

- 사업면적이 3만㎡를 넘으면 **"매장유산 확인 필요"** 로 표시
- 근거는 삭제된 조문이 아니라 **개발행위허가·인허가 협의 단계에서 관할
  지자체·국가유산청이 요구하는 실무**임을 밝힌다
- **가부를 선고하지 않고** 국가유산청 확인처를 안내한다

> 면적 기준(3만㎡)은 **실무 관행으로서의 참고선**이며 현행 법정 의무가 아니라는
> 사실을 문구에 명시한다. 이것을 밝히지 않으면 보고서를 읽는 사람이 법정
> 의무로 오인한다.

**면적 기준**은 말씀하신 대로 **조건부 포함 사업가능 면적**(가용 + 조건부)을 씁니다.
배제 면적은 애초에 사업 대상이 아니므로 분모에서 뺍니다.

## 3. 농지 — 전용 경로를 걷어내고 일시사용으로 통일

당사 표준이 **염도평가 → 타용도 일시사용허가**라는 확인에 따라 바꿉니다.

### 3.1 법적 근거 (원문 확인)

| 단계 | 근거 | 내용 |
|---|---|---|
| 상위 | 농지법 **제36조제1항제4호** | 전기사업 목적 태양에너지 발전설비 → **타용도 일시사용허가** |
| 위임 | 같은 호 **가목** | "토양 염도가 일정 수준 이상인 지역 등 농림축산식품부령으로 정하는 지역" |
| 기준 | **시행규칙 제31조의2제1항** | **사업구역 내 농지면적의 100분의 90 이상**이 **필지별 토양 염도 5.50 dS/m 이상** |
| 절차 | 같은 조 제2항 | 측정 절차·기관·비용·결정방법은 농식품부장관 고시 |

### 3.2 농업진흥구역 안에서도 가능하다

농지법 **시행령 제29조제7항제7호** — 농업진흥구역에서 할 수 있는 행위에
**태양에너지 발전설비**가 명시되어 있습니다(각 목의 어느 하나에 해당하는 것).

따라서 농업진흥지역·농림지역 판정을 **'사실상 불가'로 읽히게 두면 안 됩니다.**
조건부로 두되 사유에 **일시사용 경로로 사업 가능**을 앞세웁니다.

### 3.3 전용 경로는 대안으로만

농지법 **시행령 제44조제6호** — 태양에너지 발전설비로서 부지 농지면적이
**3만㎡(3ha)를 초과**하면 **농지전용허가 제한대상**입니다.

당사는 전용을 쓰지 않으므로 인허가 로드맵에서 **전용허가를 대안 경로로 내리고**,
일시사용을 표준 경로로 앞세웁니다. 3ha 제한은 "전용을 택하더라도 막힌다"는
근거로 각주에 남깁니다.

## 4. 계통 연계 — 도로 기준 거리 (구현 가능 확인)

가능합니다. 공개 라우팅으로 실측했습니다.

```
홍성 구역 → 인근 지점   직선 6.6km  vs  도로 9.36km (15분)
```

직선거리만 보면 **연계 선로 길이를 30~40% 과소평가**합니다. 실제 계통 연계는
지중·가공 선로를 **도로를 따라** 포설하므로 도로 거리가 공사비에 직결됩니다.

### 표시 방식

```
최근접 변전소   ○○변전소 (154kV)
  직선거리      6.6 km
  도로거리      9.4 km  ← 선로 포설 기준 (도로망 경로)
```

둘을 **나란히** 냅니다. 도로거리 하나만 내면 그것이 확정 경로인 줄 읽히는데,
실제 포설 경로는 한전 협의로 정해집니다. 라우팅 실패 시 직선거리만 내고
그 사실을 밝힙니다.

## 5. 출력제어 · 소음/반사광 — 참고 표기만, 점수 미반영

말씀대로 **점수와 이용률 산정에 관여하지 않습니다.**

- **출력제어 이력** — 인근 지역에서 출력제어가 발생한 사실이 있으면
  "참고: 인근 사업지에서 출력제어 발생 이력이 보고된 지역입니다"로만 표기
- **소음·반사광 민원** — 주민 수용성 참고. 확인처(지자체 민원·환경분쟁조정위원회)
  안내까지만

둘 다 `사업성` 범주의 **참고 항목**으로 두고 판정은 `확인 필요`가 아니라
**정보 표기**로 처리합니다. 점수 산식에 들어가지 않습니다.

## 6. 공역 레이어 — 태양광 판정에서 제외

모듈 높이 3~5m로는 **고도 기준 공역에 저촉되지 않습니다**. 풍력 200m 터빈과 다릅니다.

제외 대상 (10종):
관제권 · 비행제한구역 · 비행장교통구역 · 군작전구역 · 훈련구역 ·
공중전투기동훈련장 · 항공위험구역 · 접근관제구역 · 경계구역 · 공중급유구역

**비행금지구역은 남깁니다** — 지상 시설 설치도 통제될 수 있어 성격이 다릅니다.

이건 성능이 아니라 **오판 제거**입니다. 지금 태양광 필지가 `접근관제구역`,
`경계구역`에 걸려 조건부로 뜨는 것은 잘못된 판정입니다.
