## 1. 문서 개요

### 1.1 목적

현재 구축된 풍력 입지타당성 검토 시스템이 **무엇을 하고, 무엇을 하지 않으며, 어떤 근거로 판정하는지**를 기술한다. 기능 소개가 아니라 명세를 목적으로 하며, 판정 결과를 해석하거나 시스템을 이어받아 개발·운영할 때의 기준 문서로 쓴다.

### 1.2 범위

| 포함 | 제외 |
|---|---|
| 육상풍력 입지 규제 자동 스크리닝 | 해상풍력 |
| 지자체 이격거리 조례 판정 | 발전량·수익성 시뮬레이션 |
| 검토 보고서(docx) 생성 | 인허가 서류 작성·제출 |
| 배치안 저장·비교 | 계약·금융 검토 |
| 인허가 절차 로드맵 조회 | 실시설계·구조 검토 |

### 1.3 이 시스템이 하지 않는 것

명세의 일부로서 먼저 밝힌다.

- **인허가 가부를 판정하지 않는다.** 근거 규정과 확인처를 붙여 담당자가 확인할 것을 좁혀 주는 데까지가 역할이다.
- **법령에 없는 금지를 만들지 않는다.** 판정 규칙은 조문에 근거하며, 조문이 예외를 허용하는 항목은 「불가」가 아니라 「조건부」로 둔다.
- **모르는 것을 추정으로 메우지 않는다.** 자료가 없거나 기준이 없으면 「확인 필요」로 남기고 그 사유를 구분해 표기한다.

## 2. 시스템 개요

### 2.1 정의

지도에서 지정한 사업지(발전기 배치선 또는 사업 구역)를 입력으로 받아, 공공 공간정보·법령·조례 데이터를 조회해 **규제 62개 항목을 판정**하고 **가용면적을 산출**하며 **검토 보고서(docx)를 생성**하는 웹 시스템.

### 2.2 사용 흐름

```
① 사업지 지정      지도 클릭 → 발전기 위치(1~N호기) 또는 구역 폴리곤
                   주소·시·도·시·군·구 자동 입력 (역지오코딩)
                   검토반경 · 설비용량 · 발전사업허가일 입력

② 검토 실행        외부 API 병렬 조회 → 항목 판정 + 면적 4분할
                   지점 3곳 이하는 규제 항목까지 즉시, 초과 시 별도 호출

③ 보고서 생성      docx 다운로드 (진행률 표시 · 중단 가능)

④ 배치안 저장      사업별 배치안으로 좌표·조건·요약 저장
                   불러오기 → 지도·조건 복원 → 재검토
```

### 2.3 검토 모드

| 모드 | 입력 | 검토 범위 | 용도 |
|---|---|---|---|
| **지점·배치선 검토** | 1호기부터 순서대로 클릭 | 발전기 원(기본 500m) ∪ 연결선 회랑(기본 100m) | 발전기 위치가 정해진 단계. 지점 1곳이면 단일 지점 검토와 동일 |
| **구역 검토** | 폴리곤 꼭짓점 3개 이상 | 폴리곤 내부 | 구역만 정해진 초기 단계 |

**이격거리 조례는 발전기 위치에만 적용한다.** 조례가 규율하는 대상은 발전시설이며 집전선로·진입도로가 아니다. 연결선 회랑은 검토 범위에는 포함되나 이격 판정의 기준점이 되지 않는다.

## 3. 판정 체계

### 3.1 판정 4단계

| 기호 | 판정 | 정의 | 면적 집계 |
|---|---|---|---|
| ● | 불가 | 조문이 직접 금지 | 배제 |
| ▲ | 조건부 | 협의·저감·예외 절차로 진행 가능 | 조건부 |
| ◇ | 확인 필요 | **자동 판정하지 않음** | 보류 또는 제외 |
| ○ | 해당없음 | 검토 범위에 해당 사항 없음 | 제약 없음 |

현재 「불가」로 등록된 레이어는 **비행금지구역 하나**다. 생태자연도 1등급, 백두대간 핵심구역 등은 법률상 예외 행위가 있어 「조건부」로 둔다.

### 3.2 「확인 필요」의 사유 구분

재시도로 해소되는 것과 아닌 것을 구분한다. 이 구분이 없으면 담당자가 무엇을 해야 할지 알 수 없다.

| 사유 | 뜻 | 조치 |
|---|---|---|
| 인증키 미설정 | `.env`에 키가 없음 | 키 등록 후 재실행하면 판정됨 |
| 조회 실패 | 외부 API 오류·차단 | 재실행 시 판정될 수 있음 |
| 자료 없음 | 해당 지점에 자료 미구축 | 재실행해도 동일 |
| 판정 기준 없음 | 자료는 받았으나 규칙 미등록 | 임의 판단하지 않음 |
| 자동 판정 대상 아님 | 현장 실측·기관 협의 필요 | 자동화로 대체 불가 |

### 3.3 판정 근거의 신뢰도

모든 항목에 근거의 단단함을 함께 표기한다.

| 표기 | 뜻 |
|---|---|
| 원문 확인 | 법령·조례 원문을 직접 대조 |
| 교차 확인 | 공공 API 응답을 근거로 산출 |
| 참고 수준 | 보조 지표이거나 자료 누락 가능 — 실사·실측 필요 |

### 3.4 종합 점수 산식

100점에서 세 가지를 뺀다. **불가 항목이 하나라도 있으면 산식과 무관하게 0점.**

```
점수 = 100 − worst − spread − gap

worst    가장 불리한 한 항목의 (판정 감점 + 난이도 감점)   리스크의 크기
spread   (조건부 항목 수 − 1) × 3점                       리스크의 개수
gap      확인 필요 항목 수 × 2점                          정보 부족
```

| 판정 감점 | | 난이도 감점 | |
|---|---:|---|---:|
| 해당없음 | 0 | 낮음 | 0 |
| 확인 필요 | 6 | 보통 | 4 |
| 조건부 | 12 | 높음 | 9 |
| 불가 | 100 | 치명 | 18 |

감점을 단순 합산하지 않는 이유: 검토 레이어를 늘릴수록 점수가 나빠지면 **데이터가 좋아진 것을 나쁜 결과로 표시**하게 된다.

여러 호기를 검토할 때는 **가장 나쁜 값**을 종합 판정으로 쓴다. 한 기라도 걸리면 그 항목은 해결해야 하기 때문이다. 점수는 후보지 간 상대 비교 지표이며 법적 판단이나 절대 기준이 아니다.

### 3.5 면적 4분할과 가용면적

```
배제        불가 판정 레이어 ∪ 조례 이격거리 위반 범위
조건부      조건부 판정 레이어 (사유별 면적을 별도 집계)
제약 없음   위 어디에도 걸리지 않음
판정 보류   조례를 확인하지 못한 지자체 구간 · 조회 실패 레이어
```

가용면적은 **하나로 말하지 않고 두 가지로 병기**한다. 어느 쪽을 쓸지는 사업 판단이지 계산의 몫이 아니다.

```
엄격 가용    = 아무 규제 레이어에도 걸리지 않는 면적
협의 포함    = 엄격 가용 + 조건부 면적
```

**별도 축으로 빼는 것**

- **용도지역 4종**(도시·관리·농림·자연환경보전)은 전 국토를 빈틈없이 나눈 분류라 어느 구역을 그려도 합이 100%가 된다. 함께 집계하면 산간 구역에서 농림지역이 조건부 면적을 독점해 나머지 제약이 묻힌다.
- **구역 전체를 99.5% 이상 덮는 레이어**는 구역 내 위치를 가르지 못하므로 면적 분할에서 빼고 '구역 전체 조건'으로 표기한다. 판정 자체를 지우는 것이 아니다.

## 4. 기능 명세

### 4.1 사업지 지정

| 기능 | 내용 |
|---|---|
| 지도 배경 | 위성영상(기본) · 일반지도(V-World/OSM) · 지형·등고선, 지명·경계 표기 |
| 지점 지정 | 클릭으로 1호기부터 순차 지정, 최대 10곳 주소 표시 |
| 지정 취소 | `Esc`·되돌리기로 마지막 지점 취소, 번호 클릭 시 해당 기 삭제, 지우기 |
| 검토반경 | 발전기 반경(기본 500m) · 연결선 반경(기본 100m), 각 50~20,000m |
| 시각화 | 반경을 실제 미터 기준으로 지도에 표시 (연결선은 폭이 있는 띠) |
| 주소 자동 입력 | 좌표 → 지번주소·시·도·시·군·구 (시·군·구는 조례 조회 기준으로 정규화) |
| 발전사업허가일 | 연·월·일 3칸 분리 입력 — 자릿수 강제 및 커서 자동 이동 |

### 4.2 규제 검토

| 기능 | 내용 |
|---|---|
| 항목 수 | 62개 / 7개 영역 |
| 조회 방식 | 레이어별 병렬 조회(최대 동시 6), 실패한 레이어는 전체를 중단시키지 않고 '조회 실패'로 보고 |
| 결과 병합 | 호기별 판정을 항목 단위로 합쳐 **가장 나쁜 값**과 **해당 호기 번호**를 함께 표기 |
| 해당 호기 표기 | `1~10호기 (전 호기)` · `1·3~5·9호기 (5기)` · `7호기` |
| 상세 조회 정책 | 지점 3곳 이하는 자동 포함, 초과 시 버튼으로 별도 호출(수 분 소요) |

### 4.3 지자체 조례 처리

| 단계 | 처리 |
|---|---|
| 행정구역 분할 | 검토 범위를 시·군·구 경계로 분할해 **조각마다 해당 지자체 조례를 적용** |
| 조례 수집 | 자치법규 OPEN API로 원문 수집. 도시·군계획 조례 + **풍력·재생에너지·이격거리 별도 조례**까지 검색 |
| 조문 판독 | 조문 → 별표 순으로 탐색. 첫 조례에 규정이 없으면 다음 후보로 이동 |
| 거리 추출 | `2,000미터` / `2000m` / `1.5킬로미터` 표기 및 `(단, 5호 미만은 500미터)` 단서 해석. 이격거리가 아닌 수치(울타리 높이 등)는 문맥으로 제외 |
| 대상 분류 | 주거밀집 / 축사·생산시설 / 정온시설 — 조례별 명칭 차이를 흡수 |
| 주거밀집 판정 | 건축물대장 주용도로 주택만 골라 **50m 연쇄 군집**으로 호수를 세고, 5호 이상/미만에 다른 거리 적용. 부속 건축물은 조문에 따라 제외 |
| 경과규정 | 조례 시행일과 **경과조치를 담은 개정의 시행일**을 구분 저장. 발전사업허가일이 앞서면 검토 대상으로 표시하고 부칙 원문 첨부 |

**상태 구분** — 조례가 비었을 때 세 가지를 구분한다. 뭉뚱그리면 규정이 없는 것으로 오독된다.

| 상태 | 뜻 |
|---|---|
| 규정 있음 | 이격 기준을 추출해 적용 |
| 규정 없음 | 조문·별표를 모두 판독했고 풍력 이격 조항이 없음 (확정 정보) |
| 미확인 | 조례를 못 찾았거나 API 인증 실패로 물어보지 못함 |

### 4.4 보고서 (docx)

| 구성 | 내용 |
|---|---|
| 표지 | 검토 대상·면적(ha·평 병기)·관할 지자체 배분·검토반경 |
| PART 1 종합 판정 | 판정·점수 범위·항목 집계·가용면적·풍황·계통 + **점수 산식과 실제 계산 과정** |
| PART 2 입지조건 종합평가 | 62개 항목을 영역별 표로. 조건부·확인 필요 항목은 **근거 규정과 확인 방법·조회처**를 별도 표로 |
| PART 3 호기별 종합비교표 | 호기별 판정·점수·불가/조건부 건수·풍황(허브고도 100m 환산)·계통(154kV 우선) |
| PART 4 리스크 요약 | 배치를 바꿔도 남는 공통 제약 / 일부 호기만 해당하는 제약 |
| PART 5 면적 분포·가용면적 | 4분할 + 엄격/협의 포함 병기. 시군구 경계 밖 비중이 5% 초과 시 경고 |
| PART 6 제약도 | 위성영상 위에 배제·조건부·제약없음과 발전기 위치 중첩 |
| PART 7 제약 사유별 면적 | 무엇이 얼마나 차지하는지 + 구역 전체 조건 + 용도지역 구성 |
| 이후 | 풍황 상세·KIER 고도별 자원·전력계통·공급가능 변전소·정온시설·조례 경과규정 |

**문서 편의** — 바닥글 쪽번호(필드), 표 머리글 반복, 행 분리 방지, 문장 미절단.

### 4.5 배치안 관리

| 기능 | 내용 |
|---|---|
| 저장 | 사업명 아래 `배치안 1, 2…`. 좌표·검토반경·설비용량·허가일·행정구역·요약 |
| 불러오기 | 지도와 검토 조건 복원. **검토 결과는 비우고 재실행을 유도** |
| 비교 | 배치안 2개 이상 선택 시 요약 비교표 |
| 메모 | 배치안별 이름·메모 편집 |

**판정 전문은 저장하지 않는다.** 규제·조례는 개정되므로 몇 달 뒤 옛 판정을 그대로 펼치면 현재 값으로 오독된다. 좌표와 조건만 남기면 언제 불러도 그 시점의 규제로 다시 판정할 수 있다. 요약은 **산출 시점과 함께** 표기한다.

| 기능 | 내용 |
|---|---|
| 인허가 로드맵 | 설비용량 기준 절차·소관·법정처리기간·선행관계 |
| 관련 법령 | 16건, 원문 확인 여부 표기 |

### 5.3 법정동코드 체계 불일치

행정구역 개편 지역에서 **지적·지오코딩과 건축물대장·NED의 법정동코드가 다르다.** 앞 5자리(시도 2 + 시군구 3)만 어긋난다.

```
지적 · 지오코딩   12850 31028   전남광주통합특별시 완도군 군외면
대장 · NED        46890 31028   전라남도 완도군 군외면
```

**앞자리를 훑어 맞추지 않는다.** 뒤 14자리를 고정하고 앞을 훑으면 응답이 오는 조합이 여럿 나온다(완도군 필지 조회 시 고흥군에서도 응답). 응답이 왔다는 것은 맞는 필지라는 증거가 아니다.

대신 **건축물대장 응답의 소재지 주소로 대조**해 시군구명·읍면동명이 함께 맞을 때만 대응표에 기록한다.

```
python manage.py map_legacy_codes --lat <위도> --lng <경도>
→ 확인 — 12850 → 46890  (대장 소재지: 전라남도 완도군 군외면 …)
```

대응표는 `backend/data/pnu_legacy_sigungu.json`에 저장되며, 코드 수정 없이 다음 검토부터 반영된다. 확인되지 않으면 연결하지 않고 사유를 항목에 표기한다.

첫 생성이 오래 걸리는 이유는 호기마다 62개 항목을 외부 API로 조회하기 때문이며, 응답은 캐시되어 같은 지역의 재검토는 크게 빨라진다.

## 8. 제약사항

보고서 본문에도 동일하게 명시된다.

| 구분 | 내용 |
|---|---|
| 건물이 아닌 이격 대상 | 도로 등은 건물 레이어로 버퍼를 만들 수 없어 면적 산출에서 제외. **제외 사실과 조항을 명시** |
| 건축물대장 미등재 | 13~18%가 미등재. 무허가·농막·폐가일 수도, 실거주 주택일 수도 있어 버퍼 없이 '용도 미확인 N동'으로 별도 집계 |
| 실거주·빈집 | 공개 자료 없음. 조례 이격 면적은 **대장상 주택 기준의 상한선** |
| 군사·항공 일부 | 통제·제한보호구역, 비행안전구역 제1~6구역은 좌표 기반 공개 API 없음 — 관할부대 협의 |
| 계통 접속 용량 | 확정 용량은 한전 협의 사항. 공표 여유용량은 조회 시점 스냅샷이며 선점으로 변동 |
| 변전소 좌표 | 국가보안시설로 비공개. 한전 자료는 명칭이 첫 글자만 공개되어 특정 불가, 거리 판정은 OSM 의존 |
| 풍황 | 관측소·재분석 기반 허브고도 환산 추정. 국지 지형 효과 미반영 — 현장 실측 최소 1년 필요 |
| 해상·경계 밖 면적 | 어느 조례도 적용되지 않아 '제약 없음'으로 집계. 5% 초과 시 경고 표시 |
| 조례 커버리지 | 현재 6개 지자체 26건 등록. 미등록 지자체는 검토 중 자동 수집 시도 |

## 9. 운영

### 9.1 기동

```bash
docker compose up -d
# → http://localhost:5173  ·  풍력 입지검토 메뉴
```

### 9.2 인증키

`.env`에 등록한다. 키가 없는 항목은 「확인 필요」로 표시되며, 화면의 **데이터 연동 현황** 탭에서 어느 키가 비었는지 확인할 수 있다.

**국가법령정보 API 주의** — 인증키(OC)와 **별개로 계정에 등록된 서버 공인 IP를 대조**한다. 등록 IP와 다르면 거절되며, 이때 조례는 '없음'이 아니라 '미확인'으로 처리된다. 유동 IP 환경에서는 IP가 바뀔 때마다 재등록해야 한다.

```
open.law.go.kr → OPEN API → OPEN API 신청 → 서버 IP 등록
```

### 9.3 운영 주의

- 인증키는 소스·문서·커밋에 남기지 않는다. `.env`만 사용한다.
- 보고서의 판정은 생성 시점 기준이다. 규제·조례 개정 후에는 재실행해야 한다.
- 조례를 새로 등록했거나 개정을 반영한 뒤에는 해당 지역 캐시가 만료된 다음 반영된다.
