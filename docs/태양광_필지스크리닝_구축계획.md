### 0.1 조례 판독에서 잡아낸 함정 (기록)

태양광으로 넓히자 드러난 오류를 이번에 고쳤습니다. 남겨 둡니다 — 다른 지자체에서 재발할 수 있는 유형입니다.

| | 내용 |
|---|---|
| 증상 | 해남군 태양광 이격거리를 **제18조의2(용어의 정의)** 에서 뽑았다 |
| 원인 | 정의 조에 "주택호수 산정 기준 … 직선거리 100미터", "몽리민이란 … 반경 500미터"가 있어 거리 수치로 잡혔다. 조 번호가 앞서 먼저 걸렸다 |
| 왜 풍력에선 안 나왔나 | 그 정의 조에 '풍력'이 없어 애초에 후보가 되지 않았다 |
| 위험도 | **높음** — 실제 기준(제19조의3: 도로 100m·주거 500m)과 우연히 비슷해 눈으로도 알아채기 어렵다 |
| 조치 | 조제목에 '정의'가 든 조는 이격 조항으로 채택하지 않는다 |

## 3. 일정안

3~4주 해커톤 기준. **키 발급이 늦어도 개발이 멈추지 않도록** 순서를 잡았습니다 — 해당 항목은 '인증키 미설정 = 확인 필요'로 정직하게 표시하고 진행합니다(§7.7 대응 방침).

| 주차 | 개발 (🤖) | 병행 (🙋) | 마일스톤 |
